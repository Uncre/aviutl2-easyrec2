# 簡易録音2

AviUtl ExEdit2の画面内からマイク録音し、録音開始時のカーソル位置へ音声を自動追加する64bitプラグインです。動画をプレビュー再生しながらアフレコできます。

## 主な機能

- WAV / FLAC / MP3 / AAC (M4A) / Opus出力
- 録音中の経過時間を0.1秒単位で表示
- 録音開始位置からプレビューを自動再生
- 録音した実時間どおりの長さでタイムラインへ追加
- サンプルレート、モノラル／ステレオ、品質を選択
- WASAPI録音とWindows互換録音への自動フォールバック

## 必要環境

- Windows 10/11 64bit
- AviUtl ExEdit2 2.1.0以降
- 64bit版 `ffmpeg.exe`

FFmpegは同梱していません。FLACやOpusなどをタイムラインへ自動追加するには、その形式に対応する入力プラグインも必要です。
